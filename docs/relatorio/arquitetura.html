Arquitetura do Nupdec Conecta

backend único · dois clientes · fluxo alerta → confirmação → ocorrência
Fontes de alerta
externo

Cemaden / INMET

Avisos geo-hidrológicos e meteorológicos (webhook ou consulta periódica).

humano

Coordenador da Compdec

Alerta manual no painel: tipo, severidade, área (áreas de risco, desenho ou município), mensagem.

↓ payload / RPC criar_alerta
edge function

ingerir-alerta

Normaliza o payload externo, resolve a geometria, deduplica por origem_ref e insere em alertas.

Supabase sa-east-1 · Postgres 17

auth

Supabase Auth

E-mail + senha; JWT com papel (membro, agente, coordenador) lido pela RLS.

dados

Postgres + PostGIS

municípios · núcleos (polígono) · membros · dispositivos · áreas de risco · alertas · entregas · ocorrências · mensagens. RLS por linha.

arquivos

Storage

Bucket privado ocorrencias; fotos por URL assinada (1 h).

edge function

disparar-alerta

ST_Intersects(núcleo, alerta) → uma entrega por membro aprovado → push em lotes de 100 → tickets.

edge function

recibos-push

Lê recibos do Expo, marca entregue/falha, remove tokens mortos. Cron 15 min.

tempo real

Realtime

Mudanças em entregas, ocorrências, alertas e mensagens chegam ao painel e ao app sem recarregar.

indicadores

Views SQL

v_alerta_confirmacao (% confirmado em 10 min, mediana), v_nucleo_atividade, v_municipio_resumo.

operação

GitHub Actions · keep-alive

Ping a cada 12 h até 01/11/2026 para o plano free não pausar durante a avaliação.

Clientes
push

Expo Push Service → FCM

android

web

Painel da Compdec (React + Vite)

Núcleos, áreas de risco, novo alerta com prévia de alcance, acompanhamento ao vivo, triagem de ocorrências.
