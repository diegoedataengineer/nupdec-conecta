# Nupdec Conecta — contas de acesso (demonstração)
Município fictício **Vale Sereno – SP**. Todas as contas abaixo são de demonstração e usam a **mesma senha: `Nupdec@2026`**. Nenhuma pessoa real está cadastrada.
| Perfil | Onde entra | O que faz |
|---|---|---|
| Diretoria | https://nupdec-conecta.mundodosdadosbr.com/painel/entrar → vai para `/diretoria` | cria coordenações com área, cria e vincula gestores, acompanha a rede |
| Coordenador | …/painel/entrar | dispara alertas, cadastra áreas de risco e núcleos, aprovação final de membros, chat dos núcleos |
| Agente | …/painel/entrar | acompanha, faz triagem de ocorrências, chat dos núcleos |
| Líder do núcleo | https://nupdec-conecta.mundodosdadosbr.com/app/entrar | tudo do membro + pré-aprova cadastros do seu núcleo |
| Membro | …/app/entrar (ou `/demo` com 4 celulares) | recebe e confirma alertas, reporta ocorrências, chat do núcleo |
